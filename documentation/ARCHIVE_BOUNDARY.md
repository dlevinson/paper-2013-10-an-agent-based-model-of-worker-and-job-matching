# Archive Boundary

This package is for the ABODE model associated with Tilahun, Levinson. (2013). An Agent-Based Model Of Worker And Job Matching. JTLU 6(1):73–88 (2013). 10.5198/jtlu.v6i1.271.

## Included

The original NetLogo source, `abode.nlogo`, is included because the paper states that the model was implemented using NetLogo and local inspection confirms the worker/job/firm matching logic. The original HTML export is included as a companion artifact.

## Excluded

Respondent-level TBI data are excluded. The empirical source should be accessed through the appropriate external TBI source pathway. The bundled `NetLogoLite.jar` and `NetLogoLite.exe` files are excluded because they are third-party runtime binaries, not authored project code. Paper drafts, review correspondence, slides, and duplicate source copies are excluded.

## Related Public Code

The modern JavaScript port is available at https://github.com/dlevinson/abode-js. It is treated as an already public successor/pointer, not duplicated in this package.
